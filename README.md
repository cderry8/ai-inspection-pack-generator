# AI Inspection Pack Generator

A full-stack prototype that generates structured inspection reports from raw inspection notes.

## Tech Stack

- Backend: Node.js, Express
- Frontend: Next.js (React)
- Styling: Tailwind CSS
- Runtime: Nodemon (dev)

---

## Project Structure

backend/ → API server  
client/ → Frontend app  

---

## How to Run the Project

### 1. Backend and Frontend Setup

```bash
cd backend
npm install
npm run dev

cd client
npm install
npm run dev
